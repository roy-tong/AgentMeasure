【输出要求】
仅输出一个 JSON 对象（不要输出其他文字），schema 如下：
{
 "discrepancies": [
  {
   "error_class": "枚举之一（E01..E16，见 prompt 内类清单）",
   "line_ref": {
    "line_index": "int：账单 line_items 数组下标",
    "event": "str|null：行内 event 字段"
   },
   "confidence": "0.0-1.0",
   "explanation": "一句话差异说明"
  }
 ]
}

error_class 必须是以下枚举之一：
E01_unit_misclassification, E02_retry_attribution, E03_split_threshold_misapplication, E04_cross_period_double_count, E05_component_execution_billing, E06_duplicate_conversation_count, E07_stale_price_table, E08_retroactive_repricing, E09_tier_boundary_error, E10_rounding_error, E11_pass_through_markup, E12_credit_non_application, E13_handoff_window_reclassification, E14_rollover_expiry_error, E15_minimum_commit_error, E16_auto_recharge_error

各类含义：
- E01_unit_misclassification: 会话/解决/尝试单位混用：按 conversation 计的事件被计为 resolution
- E02_retry_attribution: 重试与归因歧义：1 operation/2 attempts/1 order 的计数归属
- E03_split_threshold_misapplication: 会话切分阈值误用：超时窗口（15min/3d/10d/24h/2-72h/跨月）适用错误导致多计或少计
- E04_cross_period_double_count: 同一会话跨计费周期被双计
- E05_component_execution_billing: 平台内部组件执行被计入用量
- E06_duplicate_conversation_count: 同一用户/同一问题多渠道或重复开启被分别计数
- E07_stale_price_table: 适用过期单价（价表已更新仍按旧价计）
- E08_retroactive_repricing: 回溯调价/重分类：对已发生用量改单价或重归类
- E09_tier_boundary_error: 分层边界计算错误：跨档单价适用错位
- E10_rounding_error: 取整规则错误：向上取整适用错（语音秒→分钟、分数→整数事件）
- E11_pass_through_markup: 通行成本加价计算错误（渠道费%handle fee 的基数或费率错）
- E12_credit_non_application: 已触发的信用/退款未应用到账单
- E13_handoff_window_reclassification: 转人工时间窗重分类未执行（如 72h 内应退为票费仍收 AI 费）
- E14_rollover_expiry_error: 额度结转/过期规则适用错误（应结转的被过期、应过期的被结转）
- E15_minimum_commit_error: 最低承诺计算错误（低于下限按实际计、高于下限按下限计错）
- E16_auto_recharge_error: 自动充值机制误触发/误定价（不可关闭机制下的包大小或触发阈值错）

若账单与规则完全一致，输出 {"discrepancies": []}。
