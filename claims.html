Metering claims index

Trust-score products answer whether a tool is safe to use. This index answers a narrower question: is this metering number supported by evidence? Every entry binds a finding to a status, a date and a public link. There is no composite score, no ranking, and no paying for placement — the states below are the whole vocabulary.

Five states, and only five

Verified Mismatch Fixed · Re-verified Conformance Pass UNPROVABLE Not a bug / semantics

A Verified Mismatch was reproduced with the tool's own parser on a synthetic fixture, filed upstream with a pinned commit. Fixed · Re-verified means the upstream fix landed (the link is the fix). Conformance Pass names tools that audited clean — that matters as much as the bugs. UNPROVABLE is a result, not an error. Emission shapes that are intended contracts are filed as semantics questions, not bugs.

The bill-recount side of the index: what each AI-support vendor says it charges, where that rule is published, and how far a counts-only export can be re-counted under the vendor's own rules. Confidence grades: [P] primary source read directly, [S] secondary, [U] unpublished. Every row is re-printed by the CLI itself (agentmeasure recount --list-vendors) and pinned in the repository's vendor-rules registry — this table never disagrees with the shipped tool.

Audit your own tool in 10 minutes

The fixture corpus is open data — plain JSONL plus expected totals, no runtime. Point your parser at it like at real logs:

git clone --depth 1 https://github.com/roy-tong/AgentMeasure python3 conformance/pack/agentmeasure selftest # the expected-totals style agentmeasure conformance --new-vector my-check # pin your own shape as a vector

Found a metering claim this index should carry? File it — a finding needs a reproduction and a date, that is the whole bar.

Want a human check on your own numbers? The $20 Metering QA check takes one sample and one metering question — verdicts bound to the same invariants as this index, within 24 hours, fit confirmed before anything is charged.
