# Launch case cards

Three single-page cases behind the 2026-11 launch. Every number on these cards
comes from a file already published in this repository, with its source and
date named on the card. Nothing here is a customer adoption claim or an
endorsement by any audited project.

| Card | What it shows |
|---|---|
| [tokendash #37](case-tokendash-37.md) | A merged upstream fix: one assistant message billed as three |
| [claude-hud #758](case-claude-hud-758.md) | A merged upstream fix: 1-hour cache writes priced at the 5-minute rate |
| [VibeMirror-coder-001](case-vibemirror-coder-001.md) | An independent re-measurement run through the free lane (issue #6) |

The audit behind the first two cards covered ~110 repositories
(2026-09-06 to 09-09) and filed 65+ evidence-backed findings, of which 45+
were verified accounting bugs and 23 fixes were merged or accepted upstream
([claims index](https://roy-tong.github.io/Verovo/claims.html), 2026-10-11
figures). The third card is a different kind of evidence: a third-party
submission re-measured with this repository's method, published 2026-10-30
with the submitter's permission.
