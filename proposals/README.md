# AgentMeasure Proposals

标准与指标变更的正式通道。任何人均可提案。

流程：**Draft → Discussion → Accepted → Experimental → Stable → Deprecated**

## 提交

1. 复制 `TEMPLATE.md` → `NNNN-短标题.md`
2. 在 GitHub Discussions 的 Proposals 分类发起讨论
3. 根据讨论修订，提交 PR 到 `proposals/`
4. 合入即 Draft；Experimental 至少运行一个外部验证周期后转 Stable
